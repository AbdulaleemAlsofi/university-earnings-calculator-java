# University Earnings Calculator Using Java

## Project Overview
An academic software project developed using Java as part of the Object-Oriented Programming course during the second academic level of the Information Technology program.

The project aims to apply object-oriented programming concepts by developing a university-based application that organizes information about different university-related individuals and calculates their earnings according to their respective categories: Student, Employee, and Teacher.

## Project Objectives
- Apply object-oriented programming concepts using Java.
- Understand class design and relationships between classes.
- Practice inheritance and abstraction.
- Apply interfaces and method overriding.
- Understand polymorphism through different object types.
- Organize and display information about different university-related individuals.

## Concepts and Features

- **Abstract Class:** Use the abstract `Person` class as the base class for specialized person types.
- **Inheritance:** Establish relationships between the base class and derived classes.
- **Method Overriding:** Implement the `getEarning()` method according to each person's category.
- **Interface:** Use the `Info` interface to define university information.
- **Polymorphism:** Handle different types of people through a shared structure.
- **Data Display:** Use the `print()` method to display each person's information and details.
- **Earnings Calculation:** Calculate earnings according to the implementation provided for each person type.

## Class Structure

The project includes the following main classes and interface:

- **Person:** An abstract base class containing the abstract `getEarning()` method.
- **Student:** A specialized class representing a student.
- **Employee:** A specialized class representing an employee.
- **Teacher:** A specialized class representing a teacher.
- **Info:** An interface defining the university information, including its name and email.
